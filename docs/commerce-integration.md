# Nyxi commerce boundary

Golfche Space is a static site. The Nyxi detail view and cart run in the browser and store product slugs and quantities in local storage. They do not submit orders, collect card details, charge payments, or grant downloads. Checkout remains disabled.

## Product setup

Product source data lives in `works/products/*.md`; `assets/products/catalog.js` is generated by `py build_catalogs.py` and should not be edited by hand. Copy `templates/product-template.md` to `works/products/<name>.md`, fill the product fields, and put public preview images under `assets/img/products/<slug>/`. The build validates image paths and writes the data consumed by the product detail view and cart.

Nyxi's `price` and `salePrice` remain `null` because no price or currency was supplied. Only add confirmed values. `purchaseUrl` can link to a hosted storefront or checkout page once one is selected.

Promotional WebP previews are public website assets in `assets/products/nyxi/`. The product ZIP is not in the repository. Keep downloadable packages in the selected storefront's private delivery system; never add them to `assets/` or link to a permanent public file URL.

## To enable sales

Select a hosted commerce provider that handles payment, order records, and private download delivery. Add its product URL to `purchaseUrl` only after the listing and delivery flow are live. No provider, price, checkout URL, or download service is configured here, so the site is a portfolio catalogue and not a functioning shop.

Do not add payment credentials or private tokens to this repository or browser code. GitHub Pages cannot enforce access rules for files in the deployed site.
